# JVueFlow 流程配置组件 - 操作说明

## 添加节点

- **拖拽添加**：从左侧面板拖拽节点到画布空白处释放
- **点击添加**：直接点击左侧面板的节点，会在画布随机位置创建

## 选中与编辑

- **选中节点**：点击画布上的节点，右侧弹出属性面板
- **选中连线**：点击连线（悬停时会变蓝），右侧弹出属性面板
- **取消选中**：点击画布空白处，或点属性面板右上角的 `x`
- **编辑属性**：在右侧面板修改名称、描述、坐标等，修改即时生效

## 连线

- **创建连线**：从节点的蓝色圆点（handle）拖到目标节点的蓝色圆点
- **条件分支**：条件节点的底部额外有一个 handle，拖出可创建"不满足"分支
- **连线标签**：在右侧属性面板中给连线填写标签和条件表达式

## 删除

- **删除按钮**：选中节点或连线后，右侧面板底部有红色删除按钮
- **键盘删除**：选中后按 `Delete` 或 `Backspace` 键
- **清空画布**：左侧面板底部的"清空画布"按钮

## 移动与缩放

- **移动节点**：直接拖拽节点到目标位置
- **画布平移**：鼠标拖拽空白区域
- **画布缩放**：鼠标滚轮，或使用右下角控制面板的 `+` `-` 按钮
- **适应画布**：右下角控制面板的居中按钮

## 数据操作

- **导出**：左侧面板"导出数据"按钮，下载 JSON 文件
- **导入**：左侧面板"导入数据"按钮，粘贴 JSON 数据导入

## 使用示例

```vue
<template>
  <jvueflow v-model="flowData" @change="onFlowChange" />
</template>

<script>
export default {
  data() {
    return {
      flowData: ''  // JSON 字符串
    }
  },
  methods: {
    onFlowChange(data) {
      // data 为对象 { nodes: [], edges: [] }
      console.log('流程更新:', data)
    }
  }
}
</script>
```

## 节点类型

| 类型 | 图标 | 说明 |
|------|------|------|
| 开始 | 绿色圆形 | 流程起点，只能输出 |
| 结束 | 红色圆形 | 流程终点，只能输入 |
| 任务 | 蓝色矩形 | 普通任务节点 |
| 条件 | 橙色矩形 | 条件判断，有两个输出口（满足/不满足） |
| 网关 | 紫色矩形 | 并行/排他网关 |
